# DATA-3401-Honors-Project
This repo holds the two projects that I need to finish to fulfill DATA 3401's Honors Contract.

## General description of the two projects:
**Project 1** - Quantitative Trading Backtester: A Python system that tests trading strategies against historical market data. It would use OOP to build the strategy architecture, NumPy for implementing technical indicators from scratch, Pandas for data wrangling, and Matplotlib for a performance dashboard (equity curve, Sharpe ratio, max drawdown, comparing returns vs benchmark of buy-hold method,...).

**Project 2** - ML Market Regime Classifier: A logistic regression classifier built entirely from scratch in NumPy that predicts bullish or bearish market conditions based on engineered technical features. The deliverable includes a training pipeline, evaluation metrics (accuracy, confusion matrix), and visualizations of the model's predictions overlaid on price data with colors. The classifier's output of this project would feed into the 1st project as a trade filter and used as a trading strategy that will also be backtested by the system.
